# プライバシーのこと

アイてる!? が何をどこへ送り、何をスマホに残すかをまとめました。電話の相手のことや費用など、使う前に知っておいてほしいことは [使う前に読むこと](safety.md) にあります。

**この文書は、アプリの動きの説明です。** 個人情報や通話の録音についての法律に合っていると主張するものではありません。自分の使い方に当てはまるかは、使う人が確かめてください（[safety.md の 9 節](safety.md#9-法律のこと)）。

アプリがつなぐ先は、Google と Anthropic の API と、自分で設定したサーバーだけです（お店への電話は、自分の携帯の回線でかけます）。広告や利用状況の解析の仕組みは入れていません。

## 1. 何がどこへ送られるか

**相手の声は Google に、相手の言葉の文字起こしと依頼の内容は Anthropic に送られます。**

| いつ | 送り先 | 送るもの |
| --- | --- | --- |
| 通話中と練習中 | Google（Gemini） | 相手の声（練習では自分の声）。AI が話す文（相手に伝える予約名や連絡先の番号は、この文に入ります） |
| 通話中と練習中 | Anthropic（Claude） | 相手の言葉の文字起こし（練習では自分の言葉）。依頼の内容（店名、希望の日時と人数、条件、お店に伝えること、予約名、連絡先の番号、聞かれたら伝えてよいこと）。かける先の番号は入りません。設定の「通話の考える役に Claude を使う」がオンのとき（既定でオンです）に送ります |
| 通話中と練習中（そのスイッチを切ったとき） | Google（Gemini Live） | 相手の声（練習では自分の声）と、上の依頼の内容 |
| 最初の画面の会話 | Anthropic（Claude） | 書いたことすべて。**電話番号も含みます**。自動のお店の検索には、店名、希望の日時、人数だけを使います |
| 確認の画面の「お店を調べる」を押したとき | Google（Gemini と Google 検索） | 店名、お店の電話番号、希望の日時、人数 |
| カレンダーの追加をオンにして、予約が取れたとき | Google カレンダー（スマホの同期） | 店名、日時、人数、予約名、お店の電話番号。非公開の予定にします |
| ほかの AI からの依頼をサーバーで受ける設定をしたとき | 自分で立てたサーバー | 依頼の中身と結果（[5 節](#5-サーバーに置くもの)） |

通話では、相手が出て AI の接続ができた時点から送ります。呼び出し音の間は送りません。

## 2. 送った先での扱い

送ったものは、それぞれのサービスの決まりのとおりに扱われます。アプリからは消せません。

- **Google（Gemini）**：必ず有料枠のキーを使ってください。[Gemini API の追加規約](https://aistudio.google.com/docs/terms)（2026-03-23 発効）では、無料枠に送った内容は Google の製品の改善に使われ、人が読むことがあります。有料枠は製品の改善に使われず、不正の検知のために限られた期間だけ記録されます
- **Anthropic（Claude）**：別の合意がない限り学習に使われません。一定の期間残ることがあり、規約違反の疑いがあるものはさらに長く残ります（[Anthropic の説明](https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data)）

## 3. 録音はしません

アプリは、通話の音声をファイルに残しません。ただし「録音しない」は、**相手の言葉が残らないという意味ではありません。**

- 相手の声は、処理のために Google に送られます
- 相手の言葉は、文字になって Anthropic に送られます
- 設定の「電話の記録」がオンのとき（**既定でオンです**）は、相手の発言の文字がスマホに残ります

相手に「録音はしません」と伝えるときは、文字が残ることも一緒に伝えてください。

## 4. スマホに残るもの

| もの | 中身 | 残り方 |
| --- | --- | --- |
| 電話の記録（既定でオン） | 実際に発信した電話の店名、電話番号、用件、予約の内容、結果、要約、文字起こし（**相手の発言の文字も入ります**） | 暗号化して、90 日、50 件まで。古いものから消えます。バックアップされません |
| 前回の電話の結果 | 実際に発信した最後の 1 件の店名、要約、予約の内容と予約名、折り返しが要ること、終わった日時と終わり方 | 暗号化はしていません。バックアップされず、次の電話で入れ替わります |
| 時間を指定した電話 | 依頼の内容 | 発信の時刻まで暗号化して残し、発信の直前か取り消しで消します |
| ほかの AI からの依頼 | 中身はメモリにだけ置きます。ファイルに書くのは、直近の 10 件の id と状態だけです | |
| 発信中の店名 | 店名を 1 件。番号は残しません。電話の途中でアプリが終わったときに知らせるためです | 暗号化はしていません。電話が終わると消します |

- 通話の音声と、練習の内容は残しません
- アプリのデータは、クラウドへのバックアップからも、機種変更のときの転送からも除外する設定にしています（実際の機種変更では試していません）
- 電話の記録の「コピー」を押すと、その 1 件の全部（電話番号と会話の文字を含みます）がクリップボードに入ります
- 設定の「お店からの折り返しを知らせる」をオンにしたときだけ（既定はオフ）、着信の番号を電話の記録と照らし合わせます。着信の番号はアプリの外に出さず、保存もしません
- ログに、電話番号、名前、会話の文、API キーは出しません

## 5. サーバーに置くもの

ほかの AI からの依頼を自分のサーバーで受ける設定をしたときだけ使います。設定しなければ、サーバーには何も送りません。

- 依頼の中身と結果は、サーバーのメモリだけに置きます。ディスクにもログにも書きません。終わった依頼は 24 時間で消します。サーバーを動かし直しても消えます
- Gemini と Claude のキーは、サーバーに置きません
- ngrok や Cloudflare のトンネルを使うと、その会社は仕組みの上で、依頼の中身とトークンを見られる立場にあります
- サーバーは使う人がそれぞれ立てます。人と共用しないでください（[docs/mcp-setup.md](mcp-setup.md)）

## 6. API キー

**API キーは、スマホの中だけに置きます。**

- スマホの外に出せない鍵（AndroidKeyStore）で暗号化して、アプリの中のバックアップされない場所に置きます
- APK、リポジトリ、サーバーには入れません。ログにも出しません
- スマホから Google と Anthropic へ直接つなぎます。料金はキーの持ち主に請求されます

## 7. 消すとき

- 電話の記録：設定の「記録を見る・消す」で、1 件ずつでも全部でも消せます。「電話の記録を端末に残す」を切っても、残っている記録は自動では消えません
- 前回の電話の結果：結果の画面で消せます
- API キー：設定の「消す」で、スマホの中のキーを消せます。キーそのものを無効にするには、Google AI Studio と Claude Console で削除します
- やめるときは [install.md の後片付け](install.md#9-やめるときの後片付け) のとおりにします
