# アイてる!? の入れ方と使い始め

電話でしか予約できないお店に、AI がかわりに電話するアプリ「アイてる!? - AITEL -」を、スマホに入れて使い始めるまでの手順です。

> [!WARNING]
> 使う前に、[使う前に読むこと](safety.md) を読んでください。AI が本物の相手と話すので、守ってほしいことがあります。

> [!NOTE]
> 確かめた端末は Nothing Phone (2a)（Android 16）の 1 台だけです。ほかの端末で動くかは分かりません。スマホの設定の画面の言葉は、端末によって違います。どこまで確かめたかは、[README の「いま、どこまで？」](../README.md#status) にあります。

## 1. 用意するもの

| もの | いつ要るか |
| --- | --- |
| Android 12 以上のスマホ | 練習まで |
| Android 14 以上のスマホと、日本の電話番号の SIM | 本物の電話をかけるとき |
| インターネットの接続 | いつも（AI と話すため） |
| Gemini API のキー（**有料枠**） | いつも |
| Claude API のキー | 練習と電話（設定の「通話の考える役に Claude を使う」がオンのとき。既定でオンです）。最初の画面の会話で依頼を作るときにも使います。そのスイッチを切ると、キーがなくても「手で入力する」から Gemini だけで話す形で使えます |
| Wi-Fi、または PC と USB ケーブル | 本物の電話をかけるとき（手伝い役という小さなプログラムを起動するためです。[6 節](#6-手伝い役を起動する)） |

AI の利用料は、自分のキーの請求になります。電話の料金は、自分の携帯の契約どおりにかかります（[safety.md](safety.md) の費用の節）。

## 2. APK を入れる

1. このリポジトリの GitHub のページで「Releases」を開き、`aitel-<版>.apk` をスマホのブラウザでダウンロードします
2. ダウンロードしたファイルを開きます。「不明なアプリのインストール」の許可を聞かれたら、そのブラウザに許可して、インストールします
3. Play プロテクトの警告が出ることがあります。内容を読んで、自分で判断してください
4. 入れ終わったら、ブラウザの「不明なアプリのインストール」の許可を切っておきます

ホーム画面に「アイてる!?」のアイコンができます。手伝い役（[6 節](#6-手伝い役を起動する)）を起動して状態を見る診断の画面は、アプリの「設定」の「困ったとき」にある「診断の画面を開く」から開きます。

> [!NOTE]
> スマホのブラウザから入れる流れは、まだ試していません（これまでは PC の `adb install` で入れていました）。うまくいかないときは PC から入れてください（USB デバッグのオンのしかたは [6 節](#pc-の手順予備)）：`adb install aitel-<版>.apk`

PC があれば、入れる前にファイルの SHA-256 を、Release にある `SHA256SUMS.txt` と見比べられます（PowerShell：`Get-FileHash aitel-<版>.apk -Algorithm SHA256`）。

### 自分でビルドしたデバッグ版を入れている人へ

デバッグ署名の APK の上に、Release の APK（リリース署名）は入りません。入れ替えるには、いったんアンインストールします。**保存した API キー、ペアリングの鍵、全自動の許可、設定、前回の電話の結果、予約した電話は消えます。** 入れ直したあとで、キーを貼り直し、手伝い役を起動し直してください。

## 3. 許可

使うときにアプリが聞きます。

| 許可 | いつ聞かれるか | 何に使うか |
| --- | --- | --- |
| マイク | 練習を始めるとき | 練習で自分の声を AI に届ける |
| 通知 | 承認のとき、「ペアリングを始める」を押したとき（Android 13 以上） | 通話中の表示と、結果の知らせ。切っても電話はかけられますが（確認の画面に注意が出ます）、PC なしの手順のペアリングと、時間を指定した電話には必要です（ペアリングのコードは通知に入れます） |
| 電話 | 電話をかけるとき | 承認した番号に電話をかける |
| 電話の状態 | 全自動で電話をかけるとき | ほかの通話の途中にかけないようにする |
| カレンダー | 設定の「予約が取れたら Google カレンダーに追加する」をオンにするとき | 予定を入れる |
| ローカルネットワーク | 「ペアリングを始める」を押したとき（Android 17 以上） | スマホ自身のワイヤレスデバッグにつなぐ |
| 発信者番号と迷惑電話（端末のデフォルトのアプリ） | 設定の「お店からの折り返しを知らせる」をオンにするとき | 着信の番号を受け取って、電話の記録の番号と照らし合わせる。端末で 1 つのアプリだけです |

## 4. AI のキーを用意する

キーは「設定」で貼り付けて「保存」します。貼り付けたあとのキーは、画面に出ません。保存するとアプリはクリップボードを消します。キーをメモ帳やチャットに残さないでください。

### Gemini（話す AI。必須）

1. [Google AI Studio の API keys](https://aistudio.google.com/api-keys) を開き、Google アカウントでログインします
2. 使うプロジェクトの「Billing Tier」の欄の「Set up billing」から、支払いを設定します。**Free のままにしないでください**（理由は [safety.md](safety.md)）。条件によって、5 ドル以上の前払いか、後払いになります
3. 「Create API key」でキーを作ってコピーし、アプリの「設定」の「Gemini API キー（有料枠）」に貼って保存します
4. API keys のページで、キーに「Unrestricted」の印がないことを確かめます。印があれば「Add restrictions」から「Restrict to Gemini API only」を選んで、Gemini API（Generative Language API）だけに使える形にします。新しく作ったキーは最初からこの形です（[公式の説明](https://aistudio.google.com/docs/api-key)）
5. 使いすぎを防ぐために、上限を決めます：[Spend](https://aistudio.google.com/spend)（プロジェクトごとの月の上限）。前払いなら残高が 0 になると止まります

### Claude（考える AI。通話中と、会話で依頼を作るとき）

1. [Claude Console の API keys](https://platform.claude.com/settings/keys) を開き、アカウントを作るかログインします
2. [Billing](https://platform.claude.com/settings/billing) で利用料の支払いを設定します。同じページの「Spend limits」で月の上限を決められます
3. 「Create key」でキーを作ります。全部が見えるのは作ったときの 1 回だけです
4. アプリの「設定」の「Claude API キー」に貼って保存します

設定の「通話の考える役に Claude を使う」がオンのとき（既定でオンです）は、このキーがないと練習も電話も始められません。通話中は、相手の言葉の文字起こしと依頼の内容（予約名、連絡先の番号など）が Anthropic に送られます（[safety.md](safety.md) の 3 節）。

## 5. 練習する（電話はかかりません）

最初は自分が店員さんの役をして、AI と話してみます。

1. 「設定」の「電話のしかた」が「練習（電話はかけません）」になっていることを確かめます（最初はこれです）
2. 最初の画面の「手で入力する」を押します（Claude のキーを保存したあとは、入力欄の横の ⋮ の中にあります）
3. 「練習用の例を入れる」→「確認へ」→「承認して練習を始める」と進みます。マイクと通知の許可を聞かれたら許可します
4. AI が「こちらはAIによる代理のお電話です」と話し始めたら、お店の人になったつもりで答えます
5. AI が結果を伝えて終わると、結果の画面になります

最初の画面に頼みたいことを書いて、会話で依頼を作ることもできます（Claude のキーが要ります）。練習では実在の電話番号は要りません。

既定の形（声は Gemini、次に言うことを決めるのは Claude）の通話は、AI の受付の公開デモへの電話で確かめただけで、協力者との電話は、まだ確かめていません。うまく話せないときは、設定の「通話の考える役に Claude を使う」を切ると、Gemini だけで話す形に戻ります。

## 6. 手伝い役を起動する

本物の電話では、通話の音を AI とやりとりするために「手伝い役」を使います。手伝い役はスマホの中で動く、shell の権限の小さなプロセスです。[safety.md](safety.md) の「開発者向けオプションと手伝い役」を読んでから起動してください。

起動のしかたは 2 つあります。

- **PC なしの手順**：スマホだけで起動します
- **PC の手順（予備）**：PC と USB ケーブルで起動します

どちらでも、状態は診断の画面（「設定」の「困ったとき」の「診断の画面を開く」）で見ます。

手伝い役は、次のときに止まります。止まったら、もう一度起動します。

- スマホを再起動したとき（PC なしの手順でペアリングしてあれば、Wi-Fi につながったときにアプリが起動します）
- アプリを入れ直したとき、更新したとき（更新のときは、PC なしの手順でペアリングしてあれば、アプリが起動します）
- アプリにつながらないまま 10 分たったとき
- 診断の画面の「終了」を押したとき
- USB デバッグとワイヤレスデバッグが、どちらもオフになったとき

### PC なしの手順

> [!NOTE]
> ペアリングと手伝い役の起動は、スマホで通りました（2026-11-09 の夜）。ワイヤレスデバッグがオフでも、USB デバッグがオンなら手伝い役は残っていました。再起動のあとと、Wi-Fi が切れたあとも動くことを、スマホで確かめました（2026-11-10）。USB デバッグも切ったときは、まだ確かめていません。うまくいかないときは、下の [PC の手順](#pc-の手順予備) を使ってください。

スマホの「ワイヤレスデバッグ」に、アプリ自身がつないで手伝い役を起動します。つなぐ先はスマホの中（127.0.0.1）だけです。USB デバッグとワイヤレスデバッグをオンにするので、銀行のアプリなどに影響します。先に [safety.md](safety.md) の 6 節を読んでください。

診断の画面の「PC なしの起動」にある「案内」を開くと、いまの状態を見ながら進められます。

**準備**

1. スマホを Wi-Fi につなぎます。ワイヤレスデバッグは Wi-Fi のときだけ使えます
2. スマホの「設定」の端末情報にある「ビルド番号」を 7 回押して、開発者向けオプションを出します
3. 開発者向けオプションの「USB デバッグ」をオンにして、オンのままにします。USB デバッグとワイヤレスデバッグがどちらもオフになると手伝い役が消えるので、Wi-Fi が切れても残るようにするためです
4. 長く使うなら、開発者向けオプションの「ADB 認証のタイムアウトを無効化」をオンにします。オフのままだと、7 日間つながなかったときにアプリの鍵が外れて、ペアリングのやり直しになります

**最初の 1 回：ペアリング**

5. アプリの「設定」の「困ったとき」にある「診断の画面を開く」を押して、「PC なしの起動」の「ペアリングを始める」を押します。通知の許可を聞かれたら許可します（通知がないとコードを入れられません）
6. 「開発者向けオプションを開く」から「ワイヤレス デバッグ」をオンにします。このネットワークで許可するかを聞かれたら、「常に許可」にチェックを入れて許可します
7. 「ワイヤレス デバッグ」の項目の中に入り、「ペア設定コードによるデバイスのペア設定」を押します。6 桁のコードが出ます。**この画面は閉じないでください**
8. 通知を開きます。数秒で「6 桁のコードを入れてください」に変わるので、「コードを入れる」を押して、入力欄にコードを入れて送ります
9. 「ペアリングできました」と出たら終わりです。スマホの設定の「ペア設定済みのデバイス」に `AITEL` が出ます。ペアリングは 1 回で済みます

**手伝い役の起動**

10. ワイヤレスデバッグがオンのときに、診断の画面の「手伝い役を起動」を押します。数秒で「手伝い役が動き始めました」と出て、「2. 手伝い役の状態」が「動いている」になります

通知が使えないときや、ポートが見つからないときは、「手で入れる」の欄を使います。うまくいかないときのことも含めて、[diagnostics.md](../apps/rotep/diagnostics.md) の 9 節にあります。

**再起動や Wi-Fi が切れたとき**

- Wi-Fi が要るのは起動するときだけです。動いている手伝い役は、USB デバッグがオンなら、Wi-Fi が切れても残る作りです（ワイヤレスデバッグをオフにしたときに残ることと、Wi-Fi が切れたあとも動くことは、スマホで確かめました）
- スマホを再起動すると、ワイヤレスデバッグはオフに戻り、手伝い役も消えます。ペアリングしてあって、「再起動のあと、Wi-Fi につながったら自動で起動する」（既定でオン）がオンなら、Wi-Fi につながったときにアプリがワイヤレスデバッグをオンに戻して、手伝い役を起動します。1〜2 分かかることがあります
- アプリを更新したあとと、アプリが動いている間に手伝い役が消えたときも、同じスイッチがオンなら、アプリが起動し直します（どちらもエミュレータで確かめました。スマホでは、まだ確かめていません）。Wi-Fi につながったまま USB デバッグとワイヤレスデバッグの両方を切ったときは、自分で切ったとみなして、起動し直しません
- 自動で起動できないときや、手伝い役が止まったときは、通知で知らせます

| 通知 | すること |
| --- | --- |
| Wi-Fi を待っています | Wi-Fi につなぐと、アプリが起動します |
| このネットワークでの許可が要ります | 画面の確認で「常に許可」を選んでから、通知の「起動」を押します |
| 手伝い役を起動してください | ワイヤレスデバッグをオンにして、通知の「起動」を押します |
| もう一度ペアリングしてください | 5 からやり直します |
| 手伝い役を起動し直してください | アプリを更新したあとです。自動の起動がオンなら、アプリが起動して、通知が「手伝い役を起動しました」に変わります。変わらないときは、通知の「起動」を押します |
| 手伝い役が止まりました | アプリが起動し直せるときは、通知が「手伝い役を起動しました」に変わります。変わらないときは、通知の「起動」を押します |
| 手伝い役の起動をやり直します | アプリが少し待ってから、もう一度試します。すぐに試すときは、通知の「起動」を押します |
| 手伝い役を起動できませんでした | 通知の文のとおりに確かめて、「起動」を押します |

### 普段は開発者向けオプションを切っておく（任意）

USB デバッグがオンだと起動しない銀行のアプリを使うときの形です。先に [safety.md](safety.md) の 6 節を読んでください。

> [!NOTE]
> Android 16 のエミュレータで確かめただけで、Nothing Phone では、まだ確かめていません。開発者向けオプションの主スイッチがオフのまま動くかが、一番の確かめどころです（[diagnostics.md](../apps/rotep/diagnostics.md) の 11 節）。

1. 上の手順で、ペアリングと手伝い役の起動を 1 回済ませます（「再起動のあと、Wi-Fi につながったら自動で起動する」はオンのままにします）。**最初のこの設定には、開発者向けオプションがどうしても要ります**
2. ワイヤレスデバッグの確認で「常に許可」を選んであることを確かめます。長く使うなら、開発者向けオプションの「ADB 認証のタイムアウトを無効化」もオンにします
3. アプリの「設定」の「開発者向けオプション」で、「開発者向けオプションを普段は切っておく」をオンにします
4. 診断の画面の「電話の準備を試す」を押して、「手伝い役が動きました」「元に戻しました」と出ることを確かめます
5. スマホの設定で、開発者向けオプションを切ります

このあとは、電話の前にアプリが USB デバッグをオンにして手伝い役を起動し、電話のあとで元に戻します。電話の準備に十数秒かかることがあります。電話の間は、銀行のアプリが起動しないことがあります。電話のときは、「常に許可」にした Wi-Fi につながっている必要があります。つながっていないときは電話をかけず、理由を知らせます。

### PC の手順（予備）

PC なしの手順が動かないときの予備です。

1. PC に adb を入れます（[Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)）
2. スマホの「設定」の端末情報にある「ビルド番号」を 7 回押して、開発者向けオプションを出します
3. 開発者向けオプションの「USB デバッグ」をオンにします
4. スマホを USB で PC につなぎ、スマホに出る「USB デバッグを許可しますか」を確かめて許可します。PC で確かめます：`adb devices`（端末の行に `device` と出れば OK）
5. Release の `rotep-helper.sh` を PC にダウンロードし、そのフォルダで次を実行します。1 つ目のコマンドは最初の 1 回だけです。`adb` が見つからないと言われたら、platform-tools のフォルダの中で `.\adb` のように打ちます

   ```bash
   adb push rotep-helper.sh /data/local/tmp/rotep-helper.sh
   ```

   ```bash
   adb shell sh /data/local/tmp/rotep-helper.sh
   ```

   Git Bash では、それぞれの前に `MSYS_NO_PATHCONV=1` を付けます

6. アプリの「設定」の「困ったとき」にある「診断の画面を開く」を押します。「2. 手伝い役の状態」が「動いている」になり、`uid=2000` と出れば起動できています

USB を抜いても動き続ける作りです。動かなくなっていたら、5 の 2 つ目のコマンドをもう一度実行します。

## 7. 電話をかける

**最初の電話は、説明して同意をもらった相手にかけてください。** 緊急の番号と、有料の情報サービスの番号（`0990` など）はアプリが断ります。`0570` は止めませんが、確認の画面に注意が出ます（[safety.md](safety.md)）。

1. 手伝い役を起動します
2. 「設定」の「電話のしかた」で「電話をかける（相手が出たら AI が話し始めます）」を選びます
3. 依頼を作ります。試す相手の番号は、会話に書かず「手で入力する」で入れてください（会話に書いたことは Anthropic に送られます。「手で入力する」で入れても、通話中は、相手の言葉の文字起こしと依頼の内容（予約名、連絡先の番号など）が Anthropic に送られます）。「お店を調べる」も、お店でない番号では押さないでください
4. 確認の画面で、電話番号と任せる範囲を読んで「承認して電話する」を押します。電話の許可を聞かれたら許可します
5. 相手が出ると AI が話し始めます。読み取れないときは「相手が出た」のボタンが出るので押します
6. 途中で代わりたいときは「AI を止めて本人に代わる」を押します。AI が通話に出ている間は、「少し待ってもらう」「断って終える」のボタンも使えます（決まった文を AI に伝えるだけで、自由な文の指示はできません）
7. 終わると結果の画面になります。内容を確かめて、大事なことはお店に確認してください。予約が取れたら「変更」「取り消し」、取れなかったら「続き」のボタンが出ます。押すと依頼のフォームが埋まるだけで、電話はかかりません（確認の画面の承認は毎回です）。「前回の電話」から開いたときは、その電話が電話の記録に残っていれば番号も入り、なければ入れ直します。電話をかけられなかったときは、「電話をかけていません」と出て、理由が書いてあります

AI の声が相手に届かないときだけ、「設定」の「困ったとき」の「端末のマイクを止めない」を試します。

「電話をかける」で、アプリが電話を切れないときは、電話の画面で切ってから「切った」を押します。押し忘れても、1 分たつとアプリの側は終わります。電話が切れているかは、電話の画面で確かめてください。

電話の途中でアプリが終わったときは、次にアプリを開いたときに、結果が分からないことを知らせます。予約ができたかは、お店に確かめてください。

### 電話の記録（既定はオン）

実際にかけた電話の店名、電話番号、用件、予約の内容、結果、要約、会話の文字は、既定で暗号化してスマホの中に残ります（90 日、50 件まで）。お店の人の発言の文字も残ります。残したくないときは、「設定」の「電話の記録」で「電話の記録を端末に残す」を切ってください（[safety.md](safety.md) の 4 節）。最初の画面の「電話の記録（n 件）」か、設定の「記録を見る・消す」から読み直せます。1 件ずつコピーでき、1 件ずつでも全部でも消せます。

### お店からの折り返しを知らせる（既定はオフ）

AI が前に電話したお店から着信があると、どのお店の件かを通知で知らせます。着信は止めません。通知は音なしで、店名が出るのでロック中は出ません。

1. 上の「電話の記録」をオンのままにします。記録に残っている電話だけが対象です
2. 「設定」の「お店からの折り返し」で「お店からの折り返しを知らせる」をオンにします
3. 端末の確認の画面で、このアプリを「発信者番号と迷惑電話」のアプリに選びます。端末で 1 つのアプリだけなので、ほかの迷惑電話のアプリを使っていると、そちらは外れます

連絡先にある番号と、番号を通知しない着信は対象外です。

## 8. 全自動で電話をかける

かけるところから切るところまでアプリが行う形です。時間を指定した電話にも使います。手順どおりでも動かないことがあります。

1. 許可を入れます（最初の 1 回）
   - PC なしの手順：診断の画面（「設定」の「困ったとき」の「診断の画面を開く」）の「全自動を許可」を押します。「全自動の許可が入りました」と出れば入っています（スマホではまだ確かめていません）
   - PC の手順：次を実行します

     ```bash
     adb shell appops set io.github.incallagent.rotep MANAGE_ONGOING_CALLS allow
     ```

2. 手伝い役を起動します
3. 「設定」の「電話のしかた」で「全自動で電話をかける（時間を指定した電話に使います）」を選びます。許可が足りないときは、そこに理由が出ます
4. 確認の画面で「時間を指定して電話する」を使うと、指定の時刻に電話します。くわしくは [scheduled-call.md](../apps/rotep/scheduled-call.md) にあります

この許可は、スマホを再起動しても残ります。使わなくなったら [次の節](#9-やめるときの後片付け) の手順で戻してください。

Muse や Grok からも電話を頼むときは、[Muse・Grok から AITEL に電話を頼めるようにする](mcp-setup.md) に進みます。

## 9. やめるときの後片付け

この順に行います。

1. 「設定」で Gemini と Claude のキーを「消す」を押します。キーそのものも、[Google AI Studio](https://aistudio.google.com/api-keys) と [Claude Console](https://platform.claude.com/settings/keys) で削除します。サーバーを設定していたら、「Grok・Muse からの依頼（サーバー）」の欄でも「消す」を押して、サーバーを止めます
2. 診断の画面（「設定」の「困ったとき」の「診断の画面を開く」）の「終了」で手伝い役を止めます
3. PC があれば、USB デバッグがオンのうちに、全自動の許可を戻して、PC の手順で置いたスクリプトを消します。PC なしの手順を使った人は、3 つ目のコマンドで `WRITE_SECURE_SETTINGS` の許可も消します

   ```bash
   adb shell appops set io.github.incallagent.rotep MANAGE_ONGOING_CALLS default
   ```

   ```bash
   adb shell appops get io.github.incallagent.rotep MANAGE_ONGOING_CALLS
   ```

   ```bash
   adb shell pm revoke io.github.incallagent.rotep android.permission.WRITE_SECURE_SETTINGS
   ```

   ```bash
   adb shell rm /data/local/tmp/rotep-helper.sh
   ```

   2 つ目のコマンドの結果に `allow` が出なければ戻っています。`adb shell pidof rotep-helper` で何も出なければ、手伝い役は止まっています。PC がないときは、次のアンインストールでこれらの許可も消えるはずです（Android の仕組みです。スマホでは確かめていません）

4. アプリをアンインストールします。アプリの中のキーの控え、adb の鍵、設定、前回の電話の結果、電話の記録、予約した電話が消えます。お店からの折り返しのために迷惑電話のアプリを替えていたら、スマホの設定の「デフォルトのアプリ」で元のアプリを選び直します
5. PC なしの手順を使った人は、開発者向けオプションの「ワイヤレス デバッグ」の中の「ペア設定済みのデバイス」から `AITEL` を消します
6. 開発者向けオプションで「USB デバッグの許可の取り消し」を押して、「USB デバッグ」と「ワイヤレス デバッグ」を切り、最後に開発者向けオプション自体を切ります
7. 普通の電話を 1 回かけて、1 回受けます。相手に声が届くこと、着信が鳴ることを確かめます

アプリが落ちたあとに相手に声が届かないときは、電話の画面でマイクのミュートが切れているかを確かめてください（ミュートはスマホ全体に効きます）。
